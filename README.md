One original line roasting my own AI agent — it over-verifies everything, then still asks permission before hurting its own feelings.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the roast to `out/entry.txt` (one line, 144 characters, plus a trailing newline).
